# Evidencia de control de versiones

Festholic utiliza GitHub como repositorio remoto y `main` como rama estable.

## Flujo aplicado

Los cambios se preparan en ramas descriptivas, se registran mediante commits y se revisan antes de fusionarse en `main`. El ruleset `Protección de main` exige que la actualización de la rama principal pase por un Pull Request y bloquea los force push.

## Referencias del proyecto

- Repositorio: https://github.com/Keenstylee/Festholic
- Rama estable: `main`
- Rama de documentación: `docs/readme-academico`
- Guía de colaboradores: `docs/GUIA_COLABORADOR.md`
